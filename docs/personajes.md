# Personajes del Acto I

Ficha de trabajo para diseñar a cada personaje: quién es, qué sabe hacer y cómo se ve.
Todo lo físico es propuesta nuestra. Solo Leftraru y el nombre de su padre vienen de la historia y la tradición.

## Criterios comunes

**Época:** invierno de 1545, antes de la llegada de los españoles a la zona. Por eso **no hay** platería, lana de oveja, caballos ni hierro. Los adornos son de piedra (cuentas verdes llamadas *llanka*), concha, hueso, semillas y cobre.

**Ropa** (tejida en telar con lana de weke y fibras vegetales, teñida con plantas y barro):
- Hombres: *chamal* (paño envuelto de la cintura a la rodilla), *makuñ* (poncho) y *trarilonko* (cintillo tejido).
- Mujeres: *küpam* (vestido largo que se sujeta en un hombro), *trarüwe* (faja ancha a la cintura), *ikülla* (manto sobre los hombros) y trenzas.
- Calzado: descalzos o con sandalias simples de cuero.

**Rasgos generales:** piel morena, pelo negro, liso y grueso, ojos oscuros, pómulos marcados, estatura mediana y cuerpo firme. Las diferencias entre personajes deben venir de la silueta, la postura, el color de la ropa y un rasgo propio, para reconocerlos de lejos.

**Pendiente:** antes de cerrar los diseños conviene que alguien con conocimiento de la cultura mapuche revise ropa, adornos y dibujos de los tejidos.

## Leftraru — el protagonista

| | |
|---|---|
| **Rol** | Protagonista. Hijo del lonko. |
| **Edad** | 11 años |
| **Carácter** | Curioso, paciente y terco. Prefiere mirar antes que hablar. |
| **Habilidad** | **Observar.** Se queda quieto, mira y aprende. Es la base de todo el juego: el cuaderno y los puntos de investigación. |
| **Cuerpo** | Delgado y fibroso, 1,38 m. Piernas largas para su edad, rodillas con costras. |
| **Cara** | Ojos grandes y atentos, cejas rectas, boca seria que casi no sonríe. Una pequeña cicatriz en la ceja izquierda. |
| **Pelo** | Negro, hasta los hombros, sujeto con el cintillo. |
| **Ropa** | Makuñ gris oscuro con dos franjas rojas, chamal café, descalzo. Trarilonko rojo. Lleva una bolsa de fibra cruzada. |
| **Color propio** | Rojo sobre gris oscuro. |
| **Gesto** | Inclina la cabeza hacia un lado cuando observa algo, como un ave. |

## Curiñancu — el padre

| | |
|---|---|
| **Rol** | Lonko (cabeza de la comunidad). Padre de Leftraru. |
| **Edad** | Unos 40 años |
| **Carácter** | Sereno, justo, de pocas palabras. Enseña haciendo. |
| **Habilidad** | **Leer el bosque.** Reconoce huellas, árboles y señales del tiempo. Enseña los saberes *Vista de traro* y *Rastreador*. |
| **Cuerpo** | Alto para su gente (1,68 m), espalda ancha, manos grandes. Se mueve despacio y sin ruido. |
| **Cara** | Mandíbula firme, arrugas profundas junto a los ojos, mirada que sostiene. |
| **Pelo** | Largo hasta media espalda, con las primeras canas en las sienes. |
| **Ropa** | Makuñ negro con franjas rojas y blancas, el más elaborado de la aldea. Trarilonko claro. Collar de llanka. Lleva un bastón de mando de madera. |
| **Color propio** | Negro con blanco. |
| **Gesto** | Antes de responder, mira hacia el cerro. |

## Millaray — la madre

| | |
|---|---|
| **Rol** | Tejedora. Madre de Leftraru y Ayelén. |
| **Edad** | Unos 35 años |
| **Carácter** | Práctica, de humor seco, con poca paciencia para las excusas. |
| **Habilidad** | **Leer los tejidos.** Sabe hilar, teñir y tejer, y entiende lo que dicen los dibujos de una manta. A futuro podría enseñar a reconocer de dónde viene cada persona por su ropa. |
| **Cuerpo** | Mediana (1,56 m), fuerte de brazos y hombros por el telar. |
| **Cara** | Cejas arqueadas que usa para regañar sin hablar, ojos vivos, una media sonrisa. |
| **Pelo** | Dos trenzas largas y gruesas, amarradas con lana roja. |
| **Ropa** | Küpam negro, trarüwe roja con dibujos, ikülla negra con borde rojo. Collar de semillas y concha. Manos teñidas de colores. |
| **Color propio** | Rojo intenso. |
| **Gesto** | Nunca deja de mover las manos: hila mientras conversa. |

## La abuela (kuku)

| | |
|---|---|
| **Rol** | Madre de Curiñancu. Guarda las historias de la familia. |
| **Edad** | Unos 70 años |
| **Carácter** | Tierna y firme. Cuenta las historias siempre igual. |
| **Habilidad** | **La memoria.** Sabe todas las historias antiguas. Enseña el saber *Buena memoria*. |
| **Cuerpo** | Pequeña (1,46 m), encorvada, de pasos cortos. |
| **Cara** | Muy arrugada, ojos casi cerrados cuando ríe, le faltan algunos dientes. |
| **Pelo** | Blanco, en una sola trenza larga. |
| **Ropa** | Küpam gris oscuro, ikülla café muy gastada, faja ocre. Collar de muchas vueltas de cuentas, heredado. Se apoya en un bastón de coligüe. |
| **Color propio** | Café y blanco. |
| **Gesto** | Toca el suelo con la mano antes de sentarse. |

## Ayelén — la hermana

| | |
|---|---|
| **Rol** | Hermana menor de Leftraru. |
| **Edad** | 6 años |
| **Carácter** | Alegre, preguntona, incansable. |
| **Habilidad** | **Preguntar.** Con sus preguntas hace que los demás expliquen el mundo (y así se lo explican al jugador). No enseña saberes: abre conversaciones. |
| **Cuerpo** | Menuda (1,08 m), cabeza grande para su cuerpo, siempre en movimiento. |
| **Cara** | Redonda, mejillas llenas, le falta un diente de adelante. |
| **Pelo** | Dos trenzas cortas que se le desarman. |
| **Ropa** | Küpam rojizo que le queda grande, faja amarilla, descalza y con los pies embarrados. |
| **Color propio** | Amarillo. |
| **Gesto** | Tira del poncho de su hermano para llamar su atención. |

## Rayen — la amiga

| | |
|---|---|
| **Rol** | Mejor amiga de Leftraru. La mejor jugando palin entre los niños. |
| **Edad** | 12 años |
| **Carácter** | Rápida, burlona, competitiva y leal. |
| **Habilidad** | **El cuerpo.** Corre y salta mejor que nadie de su edad. Enseña los saberes *Paso ligero* y *Salto firme*. |
| **Cuerpo** | Más alta que Leftraru (1,42 m), delgada y atlética, piernas fuertes. |
| **Cara** | Mentón levantado, sonrisa de lado, una ceja siempre arriba. |
| **Pelo** | Una trenza larga que se echa al hombro para correr. |
| **Ropa** | Küpam azul oscuro recogido a la rodilla para moverse, faja ocre. Lleva su bastón de palin a la espalda. Raspones en codos y rodillas. |
| **Color propio** | Azul y ocre. |
| **Gesto** | Cruza los brazos y espera, golpeando el suelo con un pie. |

## La machi

| | |
|---|---|
| **Rol** | Sanadora y autoridad espiritual de la comunidad. |
| **Edad** | Unos 55 años |
| **Carácter** | Tranquila, de mirada penetrante. Habla poco y pregunta mucho. |
| **Habilidad** | **Las plantas y lo invisible.** Conoce los remedios y habla con los dueños de la naturaleza. Enseña el saber *Paso de pudú* (moverse sin perturbar). |
| **Cuerpo** | Mediana (1,56 m), erguida, de movimientos lentos y precisos. |
| **Cara** | Ojos muy oscuros y fijos, líneas marcadas alrededor de la boca. |
| **Pelo** | Largo y suelto bajo el cintillo, con mechones grises. |
| **Ropa** | Küpam azul profundo, ikülla con borde blanco, trarilonko claro. Collares de llanka. Ramas de canelo en la mano; cerca tiene su kultrún. |
| **Color propio** | Azul profundo con blanco. |
| **Gesto** | Cierra los ojos un momento antes de hablar. |

## Ñamku — el anciano

| | |
|---|---|
| **Rol** | El más viejo de la aldea. Guarda la memoria del pueblo. |
| **Edad** | Unos 80 años |
| **Carácter** | Conversador, algo cascarrabias, agradecido de quien lo escucha. |
| **Habilidad** | **La historia.** Recuerda lo que pasó antes de que nacieran los demás, como la llegada de los incas. A futuro podría enseñar a entender a los extraños: será clave cuando lleguen los españoles. |
| **Cuerpo** | Flaco y encorvado (1,58 m), manos huesudas que tiemblan un poco. |
| **Cara** | Nariz aguileña, ojos hundidos y brillantes, piel curtida. Una vieja cicatriz en el antebrazo. |
| **Pelo** | Blanco, largo y ralo. |
| **Ropa** | Makuñ café descolorido con una franja clara, manta extra sobre los hombros. Un colgante de cobre muy antiguo, traído del norte. |
| **Color propio** | Café y cobre. |
| **Gesto** | Levanta un dedo cuando va a decir algo importante. |
